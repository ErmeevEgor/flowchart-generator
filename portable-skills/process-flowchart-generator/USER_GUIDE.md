# Работа со скиллом без команд и терминала

Пользователь только отправляет LLM ссылку на репозиторий, прикладывает файл с описанием процесса и выбирает один из двух запросов. Все операции с Git, файлами, Node.js, Python и генератором выполняет сама LLM.

## Первое подключение в локальном LLM-агенте

Отправьте в Codex, Claude Code, OpenCode или другой локальный coding agent:

```text
Скачай репозиторий https://github.com/ErmeevEgor/flowchart-generator в текущую рабочую папку.

Найди в нём скилл portable-skills/process-flowchart-generator и полностью прочитай его SKILL.md. Используй этот скилл для последующей генерации простых блок-схем процессов. Проверь встроенный runtime и необходимые зависимости самостоятельно.

Все операции с файлами, установкой, терминалом и запуском генератора выполняй сам. Не проси меня вводить команды. После проверки сообщи, что генератор готов, какие два режима он поддерживает и какие файлы будет возвращать.
```

После подключения продолжайте работу в том же чате.

## Одна общая схема

Приложите инструкцию и отправьте:

```text
Используй скилл process-flowchart-generator из репозитория flowchart-generator.

Создай по приложенному файлу одну общую блок-схему процесса в режиме process_only. Самостоятельно извлеки содержание файла, построй Process Model, запусти встроенный генератор и проверь полученную SVG-схему.

Не придумывай отсутствующие шаги, роли, системы, документы, условия или связи. Все технические команды выполни самостоятельно. Верни мне готовые файлы .drawio, .svg и исходный .json, а не инструкции по их созданию.
```

## Обзор и схемы подпроцессов

Приложите инструкцию и отправьте:

```text
Используй скилл process-flowchart-generator из репозитория flowchart-generator.

Создай схемы в режиме process_with_subprocesses: одну обзорную схему всего процесса и отдельные детальные схемы подпроцессов. Выделяй подпроцессы только там, где их границы подтверждаются приложенным источником. Не дели процесс произвольно и не придумывай бизнес-логику.

Самостоятельно извлеки содержание файла, создай Process Bundle, запусти встроенный генератор и визуально проверь все SVG-схемы. Все технические команды выполни сам. Верни .drawio, .svg и .json для обзора и каждого подпроцесса, а также manifest.json. Кратко перечисли, какой узел обзорной схемы раскрывает каждый подпроцесс.
```

Если источник не подтверждает границы подпроцессов, агент должен создать одну общую схему и объяснить причину.

## Веб-версия LLM

```text
Открой репозиторий https://github.com/ErmeevEgor/flowchart-generator и прочитай portable-skills/process-flowchart-generator/SKILL.md вместе с указанными в нём справочными файлами.

Сначала проверь, можешь ли ты скачать файлы репозитория, выполнить встроенный Node.js runtime и вернуть созданные .drawio, .svg и .json как файлы. Если можешь — используй приложенное описание процесса и выполни генерацию в режиме process_only полностью самостоятельно. Если в твоей среде нельзя запускать runtime или создавать файлы, сообщи об этом до начала работы и не имитируй результат вручную.
```

Для второго уровня замените `process_only` на `process_with_subprocesses` и попросите вернуть обзор, подпроцессы и `manifest.json`.
