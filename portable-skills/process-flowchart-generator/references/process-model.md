# Process Model и Process Bundle

## Process Model

```json
{
  "title": "Обработка заявки",
  "nodes": [
    { "id": "n1", "type": "start", "text": "Получена заявка" },
    {
      "id": "n2",
      "type": "action",
      "text": "Создать заказ клиента",
      "role": "Менеджер",
      "system": "1С:ERP",
      "document": "Заказ клиента"
    },
    { "id": "n3", "type": "decision", "text": "Товар есть на складе?" },
    { "id": "n4", "type": "end", "text": "Заказ передан на склад" },
    { "id": "n5", "type": "action", "text": "Сформировать заказ поставщику" }
  ],
  "edges": [
    { "from": "n1", "to": "n2", "kind": "main" },
    { "from": "n2", "to": "n3", "kind": "main" },
    { "from": "n3", "to": "n4", "label": "Да", "kind": "main" },
    { "from": "n3", "to": "n5", "label": "Нет", "kind": "alternative" }
  ]
}
```

Допустимые типы узлов: `start`, `end`, `action`, `decision`, `boundary`.

Допустимые виды связей:

- `main` — основной сценарий;
- `alternative` — альтернативная ветка;
- `return` — возврат к предыдущему действию;
- `parallel` — только явно указанное параллельное выполнение.

Правила:

- идентификаторы узлов уникальны;
- `from` и `to` ссылаются на существующие узлы;
- у `decision` минимум два исходящих ребра, каждое с непустой подписью;
- роль, система и документ добавляются только при наличии в источнике;
- вопросительная формулировка без изменения маршрута не является `decision`;
- координаты, размеры, цвета и маршруты стрелок в модель не входят.

## Process Bundle

Для `process_with_subprocesses` верхний объект имеет вид:

```json
{
  "title": "Оптовая продажа",
  "overview": {
    "nodes": [
      { "id": "o1", "type": "start", "text": "Заказ подтверждён" },
      { "id": "o2", "type": "action", "text": "Отобрать товар" },
      { "id": "o3", "type": "end", "text": "Товар отгружен" }
    ],
    "edges": [
      { "from": "o1", "to": "o2", "kind": "main" },
      { "from": "o2", "to": "o3", "kind": "main" }
    ]
  },
  "subprocesses": [
    {
      "id": "goods-picking",
      "overviewNodeId": "o2",
      "title": "Отбор товара",
      "process": {
        "nodes": [
          { "id": "s1", "type": "start", "text": "Получено задание на отбор" },
          { "id": "s2", "type": "action", "text": "Отсканировать товар" },
          { "id": "s3", "type": "end", "text": "Отбор завершён" }
        ],
        "edges": [
          { "from": "s1", "to": "s2", "kind": "main" },
          { "from": "s2", "to": "s3", "kind": "main" }
        ]
      }
    }
  ]
}
```

`id` подпроцесса использует латинские буквы, цифры, точки, дефисы или подчёркивания. `overviewNodeId` обязан существовать в `overview.nodes`. Один подпроцесс раскрывает один конкретный узел обзора; несколько подпроцессов могут ссылаться на разные обзорные узлы.
